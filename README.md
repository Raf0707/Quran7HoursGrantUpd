# Коран за 7 часов — Android

Нативное Android-приложение на Kotlin + Jetpack Compose, перенесённое из финальной Vite/React-версии проекта.

## Что реализовано

- Главная страница, поиск по 114 сурам, недавнее чтение.
- Три режима чтения: **Сура / Страница / Мусхаф**.
- Полный корпус: 114 сур, 6236 аятов, 604 страницы.
- Пословный перевод и 604 страничных JSON.
- Геометрия строк мусхафа и два режима интервалов.
- Таджвид, масштаб арабского текста, межстрочный и межбуквенный интервалы.
- Перевод и тафсир Azan.ru из исходного набора данных.
- Локальный импорт лицензированного JSON перевода/тафсира Шамиля Аляутдинова.
- Настраиваемый порядок переводов и тафсиров.
- Закладки с цветами, копирование и Android Share Sheet.
- Темы: системная/светлая/тёмная, контраст, 12 цветовых пресетов.
- Навигация по суре/аяту, странице и джузу.
- Онлайн-аудио по аятам: 5 чтецов EveryAyah.
- Особая логика Аль-Фатихи: басмала воспроизводится отдельно; аят 7 провайдера соответствует аятам 6–7 приложения.
- Повтор, следующий/предыдущий аят, перемотка, продолжение следующим аятом.
- По умолчанию `Продолжать следующим аятом = включено`, `Автоперелистывание страниц при аудио = выключено`.
- Пользовательский локальный чтец: выбор ровно 114 файлов `001.mp3/m4a … 114.mp3/m4a` с сохранением URI через Storage Access Framework.
- Встроенный **Хадр · Ахмад Дибан · 7:28:33**, тайминги всех 604 страниц и автоматический переход по страницам.
- QUL-гарнитуры загружаются по HTTPS при первом выборе и кешируются приватно приложением; при отсутствии сети используется системный Arabic fallback.
- Поддержка portrait / landscape / больших экранов без макета, привязанного к конкретному разрешению.

## Адаптивная вёрстка

Базовые размеры UI вычисляются в `AdaptiveContent` из фактически доступной области через `BoxWithConstraints`. Отступы, радиусы, touch targets, иконки и типографика выражаются через относительную единицу `AdaptiveMetrics.unit`, а основные области используют `weight`, `FlowRow`, `fillMaxWidth` и ветвление narrow/wide.

То есть в проекте нет отдельной «вёрстки под 360×800» или другого конкретного экрана.

## Открытие проекта

1. Откройте корневую папку проекта в актуальном Android Studio.
2. Установите Android SDK Platform 37, если IDE предложит это сделать.
3. Дождитесь Gradle Sync.
4. Запустите конфигурацию `app` на Android 8.0 (API 26) или новее.

Командная сборка после установки Android SDK:

```bash
./gradlew :app:assembleDebug
```

Windows PowerShell / CMD:

```bat
gradlew.bat :app:assembleDebug
```

APK после сборки будет в `app/build/outputs/apk/debug/`.

## Примечание о сборке в исходной среде

Исходный проект подготовлен с Gradle Wrapper. В среде, где генерировался архив, Android SDK отсутствовал, а внешний доступ Gradle к `services.gradle.org` / Google Maven был заблокирован, поэтому `assembleDebug` там физически нельзя было запустить. Корпус данных, XML, структура ресурсов, ссылки assets, тайминги и Kotlin-структура проверены отдельно; версии Gradle/AGP/Compose сверены с актуальной документацией Android.
